# Laneway UI

The web front end for Laneway, a kanban app.

## Language

**Mascot**:
Laneway's one character, a pebble creature named Cobble, shown only on screens that would otherwise be empty or blocked, never on a board with cards.
_Avoid_: Avatar, character, illustration, robot

**Expression**:
One fixed pose and mood of the mascot, such as welcoming or puzzled.
_Avoid_: State, emotion, variant

**Edge**:
A screen that would otherwise be empty or blocked, such as an empty state, onboarding, sign-in, a 404, or a full-page error. Edges get the mascot, the display type size, and copy with some cheek. The board never does.
_Avoid_: Empty page, splash, marketing page

**Tint step**:
The pale version of a label color, used for named label pills and mixed into a colored list.
_Avoid_: Background color, light variant

**Strong step**:
The saturated version of a label color, used for swatches and color covers.
_Avoid_: Dark variant, solid

**Swatch**:
How a label with no name shows: a small pill in its strong step with no text, named by its tooltip.
_Avoid_: Color bar, dot

**Grip**:
The grab handle button inside a card or list that carries the keyboard drag.
_Avoid_: Handle, drag icon

**Lime wash**:
The lime tint that fades out over a card after it moves, so you can find where it landed.
_Avoid_: Highlight, flash

**List strip**:
The sticky row of list names above the phone board. Tapping a name scrolls to that list.
_Avoid_: Tabs, dots, list nav

**Members panel**:
The side panel that lists a board's members by role and lets an admin change roles.
_Avoid_: Share dialog, people page
